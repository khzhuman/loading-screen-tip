A single loading-screen tip for stressed developers and AI coding agents, 113 characters:

> Tip: the AI finished your code in four seconds. You have spent forty minutes reading it. The reading was the job.

`main.ts` writes exactly that tip (no trailing newline, 113 characters) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic: repeated runs produce byte-identical output.

## Run it

```sh
node main.ts
```
